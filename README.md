# Flip Studio · Extras

Descargas de los extras de [Flip Studio](https://getflipstudio.com): fuentes, stickers, plantillas de
texto, efectos de sonido y modelos de IA. La app los instala sola desde **Extras**; no hace falta
bajar nada de aquí a mano.

Los paquetes están en el release [`packages`](../../releases/tag/packages). Cada uno está firmado
y lleva dentro el archivo de licencia de su contenido:

- Contenido propio de Flip Studio (efectos de sonido, plantillas de texto y stickers desde octubre
  de 2026): **Licencia de contenido Flip Studio**: se usa gratis en tus videos, también
  comerciales, pero no se puede redistribuir ni revender.
- Contenido de terceros (fuentes de Google Fonts, Fluent Emoji de Microsoft, Whisper de OpenAI,
  ONNX Runtime, etc.): con su propia licencia libre, indicada en cada paquete.
